# Third-Party Notices

Squiggle Species contains original workflow, validation, inference, calibration and reporting code. It uses third-party software through documented Python package interfaces.

Current runtime dependencies include:

- NumPy
- scikit-learn
- PyTorch
- Matplotlib
- ONT Bonito for optional signal embedding extraction
- pyccf5 for optional CCF5 access

Third-party packages remain subject to their own licenses. Model weights, sequencing data and third-party source code are not included in the public source archive unless their licenses explicitly permit redistribution.

Before public release or software-copyright submission, the copyright holder and contributor list must be confirmed by the project owner.
